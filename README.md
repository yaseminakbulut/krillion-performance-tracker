# krillion-performance-tracker
# Project goal
I want to track my performance in Krillion over time and identify categories where I could improve.
# MVP Scope
- Enter your completed daily dive (manually, but maybe with a screenshot later on?)
- Save results to a CSV file and load them when the program starts
- Display daily total scores and the overall average
- Compare the average of the past week's recorded Daily Dives with the previous week's once you have enough entries
- Calculate average points per question for each category
- Display the categories you are weak in

- Add graphs
